# PEA Solar Report

เว็บรายงานการตรวจสอบและบำรุงรักษาอินเวอร์เตอร์ ภาษาไทย

กรอกข้อมูล แนบภาพ ลงลายเซ็น และส่งออก PDF โดยประมวลผลภายในเบราว์เซอร์ ข้อมูลรายงานไม่ถูกส่งเข้า GitHub

## การใช้งาน
เปิด index.html ผ่านเว็บเซิร์ฟเวอร์หรือ GitHub Pages ข้อมูลฉบับร่างเก็บในเบราว์เซอร์ของเครื่องนั้น ควรใช้ปุ่มสำรองไฟล์เพื่อเก็บข้อมูลและภาพก่อนล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง

แบบฟอร์มนี้เป็นตัวอย่างสำหรับปรับใช้ภายในหน่วยงาน
